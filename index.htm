The Problem with NFTs

Why storing data on-chain is the only true way to own generative crypto art.

⚠

99.9% of NFTs are Pointers

Most NFTs only store a link pointing to a web server or IPFS gateway. As Moxie pointed out, if the server shuts down or the domain lapses, your NFT loses its image. You owned the pointer, not the art.

✔

100% Real On-Chain Art

Pioneers like Cryptopunks and OnChainMonkey proved that the code must live in the contract itself. Our smart contract algorithm creates vector SVG paths dynamically on the EVM.

🌳

Mathematically Unique

Each tree is synthesized using an Lindenmayer system (L-System). Trees might differ by slight branch angles or by single pixels, yet every single generated hash and SVG composition is completely unique and verifiable.

Standards & Specifications

  • Lindenmayer System (L-System) →

    A mathematical formal grammar introduced in 1968 used to model the growth processes of plant development.

  • Scalable Vector Graphics (SVG) →

    Resolution-independent XML vector image format computed by the EVM smart contract.

  • OpenZeppelin ERC-721 →

    The standard interface for non-fungible tokens on the Ethereum network.
